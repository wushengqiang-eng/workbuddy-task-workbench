# WorkBuddy 任务工作台

一个本地网页看板，列出 WorkBuddy 里**今天和昨天**的全部任务，点击卡片即可打开对应会话。

纯本地运行：只读本机 SQLite 数据库，不联网、不上传数据、不消耗 AI token。

> 状态：个人使用工具，Private 仓库。

## 界面

| 版本 | 入口 | 端口 | 风格 |
|---|---|---|---|
| 普通版 | `启动工作台.bat` | 8765 | 浅色、简洁 |
| 科技版 | `启动科技版.bat` | 8766 | 深色霓虹 HUD |

两个版本可同时运行，隐藏/置顶标记共用。

## 功能

- **今天 + 昨天**全部任务，一行 3 个卡片；窄屏自动降为 2 列 / 1 列
- **点击卡片** → 通过 `workbuddy://chat/<id>` 直接在 WorkBuddy 打开对应会话（浏览器首次会询问是否允许打开 WorkBuddy，选允许）
- **常用置顶**：点卡片右上 ☆ → 永久固定在顶部图标区（一行 4 个），不手动取消一直在；点图标打开，点 × 取消
- **加入今天**：老任务调到今天看 —— 点 `＋ 加入今天` → 搜标题 → 钉入
- **隐藏**：点卡片右上 × → 从工作台隐藏（**不删除真实任务**），可在「已隐藏」区恢复
- **搜索 / 筛选**：全部 / 只看手动 / 只看自动
- 每 30 秒自动刷新，也可手动点 `↻ 刷新数据`

## 安装

1. 下载本仓库（或解压 zip）到任意目录，路径不要带特殊符号。
2. 确认已装 **Python 3**（安装时勾选 "Add Python to PATH"）。
3. 双击 `启动工作台.bat`：自动启动本地服务并打开浏览器。

关闭弹出的黑色命令行窗口即停止服务。

## 数据来源

只读本机 WorkBuddy 的会话数据库 `workbuddy.db`（通常位于 `%USERPROFILE%\.workbuddy\`），**不写入、不修改任何数据**。

路径自动探测顺序：

1. 环境变量 `WORKBUDDY_DB`
2. 当前用户 home 下的 `.workbuddy\workbuddy.db`
3. 环境变量 `USERPROFILE` 兜底

换电脑、换用户名无需改代码。若都探测不到，启动前设置 `WORKBUDDY_DB` 指向数据库完整路径即可。

## 注意事项

1. **隐藏 / 置顶 / 加入今天**这些标记存在浏览器 `localStorage`，与浏览器绑定，不会随文件夹或仓库走。换机器 = 从头开始，属正常。
2. 点击任务能打开的前提是协议 `workbuddy://` 已注册（安装 WorkBuddy 后会自动注册）。
3. WorkBuddy 大版本升级后，deep link 格式若变化，打开功能可能需要回归验证。
4. 本工具仅在本机 `127.0.0.1` 监听，不对局域网开放。
